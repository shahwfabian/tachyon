C++20 · matching engine · property-based testing

A limit order book that is fast, and can prove it's correct.

Tachyon is a price-time-priority matching engine built around a flat price ladder, an intrusive order pool and per-side occupancy bitmaps. It is checked by a differential fuzzer that runs it next to a reference book, catches every planted bug, and shrinks each failure down to a handful of events.

Benchmarks

Both books replay the same pre-generated stream of orders, starting from the same pre-built book of resting orders. Each operation is timed with the CPU's timestamp counter (rdtsc). Both books must produce identical fills, or the run fails.

Differential fuzzing & shrinking

Eight realistic matching-engine bugs are planted behind a compile-time flag. For each one, the fuzzer generates random order flow and runs Tachyon and a simple std::map reference book side by side. After every event it checks that both books agree on status, fills and full book state, and that Tachyon's own invariants still hold. When a check fails, a delta-debugging shrinker removes events and simplifies values until nothing else can be removed. Click any bug to step through its minimal reproduction.

Design

Every choice below is about keeping the hot path free of allocation, branches and pointer chasing.

  • Integer ticks, one shared ladder. An uncrossed book can never hold a bid and an ask at the same tick, so both sides share a single array of price levels. The same tick can switch sides when an aggressive order clears it.
  • Cached best price and bitmap scan. The best bid and ask are kept up to date as orders arrive. The bitmap is scanned only when the best level empties, and each 64-bit word it checks covers 64 ticks.
  • Intrusive FIFO queues. Orders sit in preallocated slots linked to their neighbors by 32-bit indices, with no allocator calls. Freed slots are reused most-recent-first, so recently used memory stays in cache.
  • Exchange semantics. Trades execute at the resting order's price. Reducing an order's size keeps its place in the queue. Increasing its size or changing its price sends it to the back. Market orders never rest on the book.
  • Zero-cost planted bugs. The bug hooks are compiled in only when TACHYON_PLANTED_BUGS is defined. The benchmarked binary contains none of them.
